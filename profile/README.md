# WorkuGRC

WorkuGRC is a drafting tool for small US defense subcontractors preparing a
CMMC Level 2 self-assessment against NIST SP 800-171 Revision 2.

It asks about 85 multiple-choice questions and produces a draft System Security
Plan, a draft POA&M, and an SPRS self-assessment score computed with the DoD
Assessment Methodology. It is free.

- Site: https://www.workugrc.com
- SPRS score estimator, no sign-up: https://www.workugrc.com/score-estimator
- Security and data handling: https://www.workugrc.com/security
- Report a security problem: https://www.workugrc.com/.well-known/security.txt

WorkuGRC is not an auditor, not a C3PAO, and not legal or compliance advice.
It never accepts Controlled Unclassified Information.

The application's source code is not public.
